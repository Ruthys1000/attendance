# Gemini Decoder

כלי לפענוח ותצוגה מקדימה של פלטי Base64 מ-Gemini Labs, עם תמיכה מלאה בעברית.

## תכונות

- פענוח Base64 → HTML עם תצוגה מקדימה בסנדבוקס מאובטח
- תמיכה בעברית (RTL)
- תמיכה בקבצי וידאו MP4, Canvas ו-JavaScript אינטראקטיבי
- גרירת קבצים ישירות לממשק
- מצב כהה/בהיר

## שימוש

פתח את `docs/index.html` בדפדפן, הדבק מחרוזת Base64 ולחץ **פענח**.
